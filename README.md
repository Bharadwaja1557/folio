# folio

A minimalist **ASCII-inspired portfolio website** built with plain **HTML, CSS, and JavaScript**.  
No frameworks, no build tools — fast and readable.

---

## ✨ Features

- ASCII-style sidebar navigation
- Active page indicator (`*`) without layout shift
- Mobile + tablet menu overlay (`[menu]`)
- Sticky sidebar on desktop
- Centered content on wide screens
- Clean monospace typography (JetBrains Mono)
- Zero dependencies

---


## 🧠 Design Philosophy

- Text-first
- Terminal-inspired UI
- No unnecessary motion
- Predictable layout
- Works without JavaScript (except menu)
